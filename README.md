# Simple Blockchain Implementation in C++

A lightweight Blockchain simulation written in C++. This project demonstrates the fundamental concepts of blockchain technology, including block linking, SHA-256 hashing, and transaction logging.

## Files

- **main.cpp**: Contains the `Block` class structure and the main simulation logic.
- **sha256.h / sha256.cpp**: Implementation of the SHA-256 hashing algorithm.
- **transactions.log**: Automatically generated file where transaction details are saved.
